# 独立した補助ツール

本体とは別に導入し、必要時に手動で使う補助ツールを置きます。各directoryでソース、本体との接続、準備・実行手順、検証方法、利用上の限界をまとめます。本体の起動や依存導入では準備・実行しません。

| ツール | 用途 |
| --- | --- |
| [Luna手動client](luna-client/README.md) | ChatGPT認可を使った個別確認・説明下書き。少数の固定入力による評価結果もここに記載 |
| [Firefox拡張](firefox-registry/README.md) | 見ているサイトからWeb UIの登録確認・候補採用・保留・紹介予定へ進む。接続先は個人設定 |

認証情報、導入済みruntime、入力・生出力はGit管理外です。個人環境での所在と保持条件は非公開の運用記録で管理します。未完了作業が具体的に生じた時だけTODOへ記し、保全済みツールの一覧としてTODOを使いません。
